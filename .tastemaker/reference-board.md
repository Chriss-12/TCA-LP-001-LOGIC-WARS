# TCA Logic Wars reference board

## References reviewed

- Kahoot mobile app: https://kahoot.com/home/mobile-app/
  - Borrow: immediate answer clarity, code-first entry, high-confidence touch controls.
  - Avoid: assigning a different loud color to every surface.
- Brilliant: https://brilliant.org/
  - Borrow: centered problem focus, calm learning typography, restrained supporting chrome.
  - Avoid: content density that would slow a timed team competition.
- Wayground: https://wayground.com/
  - Attempted review. The public page required client verification, so it was not used as a visual source.

## Project direction

An approachable mobile competition arena: playful enough to feel like a game, calm enough that the question remains the focal point. Rounded geometry is a direct user request. Color communicates action and state instead of decorating every container.

## Explicit anti-references

- Neon gradient gaming dashboards.
- Repeated square cards with identical hierarchy.
- Oversized marketing copy inside the active game.
- Confetti, particles, and motion competing with answer legibility.
